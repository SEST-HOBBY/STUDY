## Descriptive claims tied to R21 to R30

1. 6.7 Network monitoring [R21, R22, R29]: "Zabbix on SRV-MON for SNMPv3 device monitoring, service availability, resource thresholds and alerts" is supported word for word by the Zabbix network-monitoring page (SNMP v1/v2c/v3 and traps, device availability and uptime, flexible problem thresholds, alerting and escalation). "Wazuh on SRV-LOG for collected security events and investigation" is supported by the Wazuh page (free and open source, XDR and SIEM, log data analysis, threat hunting, incident response). The $0 licence allocation is supported by both vendors' own wording ("no limits or hidden costs"; "no license fees, no per-device charges"; "completely free as an open source solution"). Note for the rebuild: Zabbix also sells paid support subscriptions and a hosted Zabbix Cloud; the draft's $0 is for the self-hosted software licence only, and its separate support allowance covers the rest, which is the right framing.
2. 6.8 Mail [R23]: Ubuntu's "Mail services" how-to covers Postfix (default MTA), Exim4 and Dovecot (IMAP/POP3). Supported.
3. 6.10 ISP plan [R24]: every figure checks. Plan name "Business Assurance Ultrafast Plus 1000/400"; "$160/month"; typical busy-period 875/339 Mbps (the page labels it "Typical busy speed 9am-5pm", a business-hours measure, not an evening figure); free static IP; "Priority restoration with nbn Gold eSLA"; FTTP is the only eligible connection type, so "requires FTTP eligibility" is correct. The draft's wording "1000 Mbps download / 400 Mbps upload access tier, not symmetric 1 Gbps dedicated fibre" is also consistent with the page (nbn Enterprise Ethernet and Aussie Fibre are separate products on the site). The page's current promotion ("Save up to $150 over 6 months") applies only to the Business Essentials tiers; Ultrafast Plus has no promotional price, so $160 is the standard rate. The Cairns $120 monthly allowance sits between the two Business Assurance tiers below it (Superfast Plus 250/100 at $114, Turbofast Plus 500/200 at $136), so it is a reasonable allowance. The page does not state whether $160 includes GST; the draft's one-line caveat should stay. "4G backup included with eligible hardware" appears on the Business Assurance cards; the draft's decision not to count a provider backup feature as a deployed second path is consistent with that.
4. 6.6 SIP trunks [R25]: the page is quote-based (Nexgen consultation, solution builder, no prices). The draft's "$600 monthly ... pending a Nexgen/Aussie Broadband quote" and "number porting ... must be confirmed" match the page ("Transfer your existing business numbers (where eligible)"; "Each SIP channel supports one simultaneous call", which is the basis for the draft's ten simultaneous calls = ten channels).
5. 2.2 Hyper-V Replica [R26]: "15-minute replication interval" is one of the three options the page gives ("regular intervals of 30 seconds, 5 minutes, or 15 minutes"). "Recovery requires controlled activation and verification; it is not automatic clustered failover" is supported: "Hyper-V Replica, by contrast, is a disaster recovery technology that maintains an asynchronous copy ... so you can manually initiate failover" and "complements rather than replaces failover clustering". "Application-consistent database backups remain necessary" is consistent with the page: default replication "protects OS state, not in-flight application state", with VSS application-consistent recovery points optional. The page also confirms no extra licence cost and that replication works between single (non-clustered) hosts, which is the draft's two-host design.
6. 6.4 and 7.3 [R27]: the Essential Eight page names all eight strategies the draft leans on: patch applications, patch operating systems, multi-factor authentication, restrict administrative privileges, application control, restrict Microsoft Office macros, user application hardening, regular backups; it defines Maturity Levels Zero to Three. Supported. The draft's "baseline for those controls" wording is appropriate; the page is a maturity model, not a certification scheme.
7. 6.5 Licensing [R28]: the guide supports each rule the draft relies on. Core minimums: "subject to a minimum of 8 core licenses per physical processor and a minimum of 16 core licenses per server. ... Core licenses are sold in 2-packs and 16-packs." Virtualisation rights: "Standard has rights to use two OSEs or two Windows Server containers with Hyper-V isolation"; the physical OSE may also run the software "if the physical OSE is used solely to host and manage the virtual OSEs" (this is the draft's "physical host is reserved for virtualisation management"). Stacking: "for each additional two OSEs ... an additional 16 core licenses must be assigned to the server"; "This practice is often referred to as 'stacking' and is allowed with Standard edition." So three 16-core sets per host = six Windows guests per host, which is what the draft budgets so that either host can run all six guests. CALs: "Each user or device that accesses licensed servers requires a Windows Server CAL" and "Required for every user or device accessing the licensed server." Caveat worth keeping in the draft: the guide covers Microsoft Commercial (volume) Licensing; the Techbuy EP2-25187 pack cited at R8 is an OEM pack, whose use rights come from the OEM licence terms. The draft already says OEM/stacking entitlement must be confirmed with the supplier, which is the right caveat.
8. 6.2 DMZ switch [R30]: the model and its role are supported (24 gigabit copper ports plus four 10G SFP+ uplinks, L3 managed, stackable, SNMPv3 management). The price is not: the page prints $1,632.00 inc GST today, not $1,578, and the unit is "Preorder (Contact Us)" rather than in stock. The $1,750 allowance in 6.9 still covers the listed price with about $118 headroom.
