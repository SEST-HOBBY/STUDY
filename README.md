# STUDY

Working repository for TAFE Queensland assessment work. Each assessment lives in its own folder so that
supplied documents, reference material and my own work are kept apart and the provenance of every file is clear.

```
<UnitCodes_ClusterName>/
  <ATn_AssessmentName>/
    00_assessment_documents/   marking criteria, portfolio of evidence, templates (supplied by TAFE)
    01_supplied_reference/     reference assets supplied with the task (floor plans, starter files, videos)
    02_student_work/           my own working files (Packet Tracer, screenshots, notes)
    03_report/                 the report being submitted
    04_extracted_views/        read-only conversions of the above (markdown, PDF, PNG, decrypted XML)
    05_analysis/               tools, checks and working analysis used to build the report
```
